# Valheim Helmsman

<img src="assets/helmsman-icon-v1.png" alt="Viking gull sailing through rough seas" width="320">

A gull-guided autopilot between your named docks. **In testing — solo worlds only.**

- Configure docks with a ship ghost and optional reverse departure.
- Sail around land, change destination, or summon an empty named ship.
- Supports Karve, Longship and compatible OdinShip boats. Rowboats need two seats.

Install both DLLs from your build into `BepInEx/plugins/ValheimHelmsman`. Requires BepInEx and Jötunn.

Build a Dock Ward, set its berth, then speak to the gull. **F8** opens ship orders; **Shift + E** at the mast or helm names a ship.
