# Carved markers — second visual pass

**Shelved — excluded from the current release at the user's request. Retain these models for possible future use.**

Four revised models: Gullwatch post, Tide serpent, Wayfinder marker and Wreckward marker.

- Irregular recessed adze marks along post corners and a tied base binding.
- Carved breast-feather marks on the gull.
- Tide serpent redesigned as a continuous tapered snake coiling 2.4 turns around an octagonal post, with an ascending neck, broad python-like head, carved eyes, nostrils and scale incisions.
- Exposed wooden fastening pegs in the compass face.
- A fine weathering crack in the skull crown.

The v1 models and renders remain as the earlier review baseline. All bases remain grounded; the compass backing disc is intact.

Each model has an editable Blender file, GLB export and fresh studio render. Geometry checks passed for finite coordinates, nonempty meshes, recorded bounds and triangle counts. See `geometry-checks.json`.

Static visual review only. Runtime registration, collision, native shader matching, animation and in-game acceptance remain pending. No local installation or public publishing was performed for this pass.

## Marker behavior

These four new models are decorative studies. No buffs, protection, navigation or other gameplay behavior has been added. Existing Totem1–Totem4 pieces are registered as harbor decoration.

The coiled Tide serpent was rebuilt and individually rendered after user feedback; the other three renders were reused when updating the review sheet.
