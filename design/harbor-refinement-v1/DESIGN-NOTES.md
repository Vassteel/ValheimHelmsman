# Harbor structures and lifting gear — original review models

Eight original models are ready for visual feedback. They are not installed in 0.2.39 and do not yet replace runtime prefabs.

| Model | Intended replacement |
| --- | --- |
| Keel cradle | ShipConstruction |
| Launching rollers | ShipConstruction1 |
| Ship framing gantry | ShipConstruction2 |
| Timber pier crane | PierCrane1 |
| Braced pier crane | PierCrane2 |
| Single block | PulleyCobia |
| Double purchase | PulleyElephantSeal |
| Heavy purchase | PulleyMarlin |

The designs use pegged timber, braced frames, visible sheaves, continuous reeved purchase ropes, seized dead ends, hooks and supported rope coils. The heavier crane has a joined A-frame crosshead. Crane decks include attachment markers for later runtime snap integration.

Each folder contains editable Blender source, a GLB and its studio render. `harbor-review.png` collects all eight. Geometry is generated by `tools/HarborModels/build.py`; it does not load the source bundle, its meshes or textures. Studio shading is a review approximation. In-game versions will need native materials, placement bounds, collision and snap validation.
