# Pelican fishing workstation

A compact freestanding fish-prep bench for an existing dock or floor, with no bundled pier or decking. Weathered timber, a repaired sagging net, an offset cutting board and fish, draped rag, grounded bucket and basket, tied rope hank, and a braced pelican perch give it a working character.

The catch chest beneath the bench uses a native Valheim Container and the workstation ZDO. Its interaction collider encloses the authored chest; the front approach remains open. Worker feet are anchored to the side perch. The production pelican is included only in review renders, and spawned separately by runtime behavior.

The existing daylight catch behavior is retained for this model pass. Next pelican pass: fly out, catch fish, return carrying one in the bill, and deposit at this workstation. No fishing pole. See ../DECOR-REMODEL-PLAN.md.

Live checks: placement on existing floors, chest interaction and inventory persistence, ward access, contents dropped on destruction, pelican perch alignment, shaders and daytime catches. No public publishing before user testing.
