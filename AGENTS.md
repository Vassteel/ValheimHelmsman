# README review rule

Before any README update, post the complete proposed README text in the conversation and ask the user what they would like changed. Wait for their explicit approval before editing README files, packaging those changes, or pushing them. Apply this to both repository and packaged READMEs. Keep drafts concise and easy to scan. Other authorized work may continue while awaiting review.

## Preferred README style

The user approved Quartermaster's current README as the style reference for future mod READMEs. Preserve its clear section headings, short grouped feature bullets, concise setup and controls, and brief gull-themed opening. The reference is ../Valheim mods/Quartermaster/README.md. Cover features without wordy prose. This style preference does not waive the draft review rule above.
